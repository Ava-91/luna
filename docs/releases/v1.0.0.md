# Luna 1.0.0

Luna 1.0.0 is the first stable release of the local-first music library cleaner.

## Highlights

- Read-only library scanning and metadata inspection.
- Exact and probable duplicate reports; no automatic duplicate deletion.
- Embedded artwork audits and reviewable replacement plans.
- Metadata normalization and safe, collision-aware rename plans.
- Explicitly confirmed apply operations with operation logs and rollback.
- Library health reports and JSON, Markdown, and text exports.
- Optional local SQLite indexing, profiles, and PySide6 desktop UI.

## Safety

Luna remains local-first and read-only by default. Changes require explicit confirmation. Apply operations can record a JSON operation log for rollback. External metadata providers are opt-in.

## Validation

The release workflow runs the complete test/lint suite, builds source and wheel distributions, installs the wheel into a fresh virtual environment, checks dependencies, and exercises the installed CLI against a newly generated disposable audio library. The test suite also covers real filesystem rename/rollback round trips and interrupted-operation recovery.
